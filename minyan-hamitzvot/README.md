# מניין המצוות – תוסף לאוצריא

תרי״ג מצוות כמניין בה״ג, הרמב״ם (ספר המצוות), הרמב״ן (השגות לספר המצוות), הסמ״ג וספר החינוך.

- **לפי המונה:** כל מונה לפי סדרו. בכל מצוה — הפסוק, העונש, ומי מהמונים מנאה. לחיצה על שם מונה מביאה למקומה במניינו.
- **במה נחלקו:** בין שני מונים — מה מנה זה ולא זה, ובמה שניהם מודים.
- **כלל המצוות:** כל מצוה שנמנתה באחד המניינים, עם סינון לשנויות במחלוקת או למוסכמות.
- **עיון במקומו:** פותח את המצוה בספר המונה שבאוצריא, ואת הפסוק בחומש.

## היכן נפתחת כל מצוה

| מונה | ספר באוצריא | כותרת |
|---|---|---|
| הרמב״ם | ספר המצוות | „מצוות עשה” / „מצוות לא תעשה” ← „מצוה ה” |
| הרמב״ן | השגות הרמב״ן על ספר המצוות | „שכחת העשין” / „שכחת הלאוין” ← „מצוה ה”. שאר המצוות — כמקומן ברמב״ם |
| ספר החינוך | ספר החינוך | „מצוה ה” (מניין המהדורות המאוחרות) |
| הסמ״ג | ספר מצוות גדול | „לאוין” ← „מצות לא תעשה ה” / „עשין” ← „מצות עשה ה” |
| בה״ג | הלכות גדולות | „הקדמה”, עם הדגשת שם המצוה |

הכותרות מושוות לפי ערך המספר, כך ש„רחצ” ו„דש” (כפי שנכתבים בספרים) מתאימים ל-298 ו-304.
הפסוק נפתח ב-`reader.openBookAtRef` (פרק:פסוק); אם אינו נמצא — בתחילת הפרק.

## מבנה

| קובץ | תפקיד |
|---|---|
| `manifest.json` | הגדרות התוסף והרשאות |
| `index.html`, `css/` | ממשק (צבעי ערכת הנושא של אוצריא) |
| `js/core.js` | לוגיקה טהורה: מספרים עבריים, רשימות, השוואה, יעדי פתיחה ואיתורם בתוכן העניינים |
| `js/otzaria.js` | גשר לאוצריא: ערכת נושא, אחסון, איתור ספר ופתיחתו |
| `js/app.js` | מסכים ופעולות |
| `js/data.js` | נוצר ע״י `tools/build_data.py` |
| `tools/` | בניית נתונים, בדיקות, מדמה גשר, אייקון, אריזה (לא נארז) |

## פקודות

```bash
python3 tools/build_data.py [db.db]   # js/data.js ממסד repwolfe/613 (בלי נתיב — מוריד מהקומיט הנעוץ)
node tools/test_core.js               # בדיקות, כולל איתור כל מצוה בתוכן העניינים של ספרי אוצריא
python3 tools/pack.py                 # אריזה ל-dist/*.otzplugin
tools/make_icon.sh                    # רינדור tools/icon.svg
```

`tools/fixtures/tocs.json` — הכותרות של חמשת הספרים מ-[otzaria-library](https://github.com/Otzaria/otzaria-library), לבדיקת היעדים.

לתצוגה בדפדפן עם גשר מדומה: `python3 -m http.server` בשורש הריפו, ואז לפתוח את `minyan-hamitzvot/tools/harness.html`.
