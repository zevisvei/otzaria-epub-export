# מחלוקות התנאים – תוסף לאוצריא

כל מחלוקת שבמשנה: מי החולקים, מי מחמיר ומי מקל, מי מחייב ומי פוטר, והלכה כמי לפי פסק הרמב״ם.

- **לפי סדר המשנה:** סדר ← מסכת ← פרק. לחיצה על המקום פותחת את המשנה באוצריא (`reader.openBookAtRef`, פרק:משנה).
- **התנאים:** בכמה מקומות נחלק, בכמה הלכה כמותו, בכמה החמיר והקל, וחבריו שנחלק עמהם.
- **בין תנא לחבירו:** כל מחלוקותיהם, כמה פסק הרמב״ם כל אחד, וכלל הפסק שבגמרא כשיש (עירובין מו:, עירובין יג:).

## הנתונים

`js/data.js` נבנה מ-`arguments.csv` של MishnaBase:

- כל מחלוקת נמנית פעם אחת, במקום הראשון שנשנית בו.
- **דעת כל חולק:** מחמיר / מקל / דעה אמצעית (`Chumra`, `Kula`, `BHB`), או מחייב / פוטר (`Chayav`, `Patur`).
- **„הלכה כמותו”:** לפי `Score` במאגר — פסק הרמב״ם.
- **שמות התנאים:** כפי שנזכרים במשנה — רבן גמליאל, רבי יוסי ברבי יהודה, בן עזאי וכו׳. המילון נמצא ב-`tools/build_data.py`, ושם שאין לו תרגום עוצר את הבנייה.
- **שם המסכת:** כשם הספר בספריית אוצריא („משנה מעשרות”, „משנה מקואות”).

## מבנה

| קובץ | תפקיד |
|---|---|
| `manifest.json` | הגדרות התוסף והרשאות |
| `index.html`, `css/` | ממשק |
| `js/core.js` | לוגיקה טהורה: מפתחות, דברי תנא, בין שני תנאים, כללי הפסק, יעד הפתיחה |
| `js/otzaria.js` | גשר לאוצריא (משותף לתוספי הריפו) |
| `js/app.js` | מסכים ופעולות |
| `js/data.js` | נוצר ע״י `tools/build_data.py` |
| `tools/` | בניית נתונים, בדיקות, מדמה גשר, אייקון, אריזה (לא נארז) |

## פקודות

```bash
python3 tools/build_data.py [arguments.csv]   # בלי נתיב — מוריד מהקומיט הנעוץ
node tools/test_core.js
python3 tools/pack.py
tools/make_icon.sh
```
